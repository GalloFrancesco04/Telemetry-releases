# Telemetry

Lap telemetry for sim racing: Assetto Corsa and iRacing, on Windows.

## Download

Get **Telemetry.exe** from the [latest release](https://github.com/GalloFrancesco04/Telemetry-releases/releases/latest) and run it. Nothing needs installing first.

Windows warns that the publisher is unrecognised because the executable isn't code signed: choose **More info**, then **Run anyway**.

Once installed, the app tells you when a newer version is out and updates itself from Settings. Each release also carries `Telemetry.exe.sha256`, so you can check a download by hand.
